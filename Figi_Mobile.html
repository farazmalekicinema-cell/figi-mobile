دریافت اطلاعات از تلگرام

در فیگی ویندوز از قسمت تنظیمات ← پشتیبان کامل JSON فایل بگیر و همان فایل را به‌صورت «Document / فایل» در تلگرام به گوشی بفرست. فایل را در گوشی ذخیره و از اینجا انتخاب کن؛ دیگر رمزی لازم نیست.

هنوز فایلی انتخاب نشده است.
⚠️ این نسخه بدون رمز است. فایل JSON در تلگرام و گزارش ذخیره‌شده روی گوشی، اطلاعات مالی را به‌صورت قابل‌خواندن نگه می‌دارند. برای ارسال فقط از حساب شخصی امن استفاده کن و روی گوشی مشترک ذخیره نکن.
📱 برای میانبر، اگر فیگی را از آدرس HTTPS باز کرده‌ای، از منوی سه‌نقطه مرورگر گزینه Install app یا Add to Home screen را بزن. فایل HTML محلی ممکن است این گزینه را نداشته باشد.
